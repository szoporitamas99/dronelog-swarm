A PROJEKTRŐL

Három szolgáltatás, egy napló

A DroneLog egy Docker Swarm környezetre készített, háromrétegű webalkalmazás.

  1. 01

    Frontend · Nginx

    Kiszolgálja ezt a felületet, és továbbítja az API-kéréseket a backendnek. Ez az egyetlen közzétett webes belépési pont.

  2. 02

    Backend · Python API

    Ellenőrzi és kezeli a feladatokat. Több replikában futtatható; a kiszolgáló azonosítója a lap alján látható.

  3. 03

    Adatbázis · PostgreSQL

    A replikák közös adatbázist használnak. A feladatokat tartós kötet őrzi, az adatbázisnak nincs nyilvános portja.

A kiszolgáló azonosítójának változása önmagában nem bizonyítja a replikaszámot. A Swarm állapotát a Docker parancsaival lehet ellenőrizni.
